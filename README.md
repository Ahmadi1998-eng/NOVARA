# NOVARA

NOVARA is an online shopping platform project designed for Afghanistan.

## About the Project

The goal of NOVARA is to build a simple, reliable, and user-friendly online shopping platform that can grow into a multi-vendor marketplace.

## Initial Features

* Display products
* Search for products
* Show product details
* Manage product prices and stock
* Build a shopping cart
* Calculate total prices
* Process customer orders

## Technology Roadmap

1. C++ — Learn programming fundamentals and implement initial logic.
2. HTML and CSS — Build the website interface.
3. JavaScript — Add interactive website features.
4. Python — Develop the backend.
5. SQL and PostgreSQL — Store and manage data.
6. Mobile development — Explore mobile app development.
